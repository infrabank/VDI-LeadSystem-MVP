# MFA 벤더 비교 — Microsoft Entra · 라온시큐어 · 드림시큐리티 · 잉카인터넷 · Okta

> **목적**: 1인 기업이 한국 시장(공공·금융·민간)에서 MFA 솔루션 딜리버리 사업을 시작할 때 1~2개 주력 벤더 선정을 위한 비교 분석.
> **결론**: **Microsoft Entra ID (1순위)** + **라온시큐어 OneAccess (2순위, 공공 특화)** 조합 권장.
> **비추천**: Okta, OneLogin (CSAP 인증 부재 → 한국 공공 진입 불가).

---

## 한국 시장 특수 요건

| 요건 | 의미 |
|---|---|
| **CSAP 인증** | 공공기관 클라우드 사용 시 필수 (Cloud Security Assurance Program) |
| **GPKI/NPKI** | 행정 전자서명 표준 — 공공기관 대다수가 사용 |
| **데이터 국내 보관** | 공공·금융 데이터 국내 리전 보관 원칙 |
| **한국 SI 파트너** | RFP 응답·기술 지원에 필수 |
| **한국어 운영 콘솔** | 공공기관 운영자 부담 감소 |

이 5가지를 모두 충족하지 못하는 벤더는 한국 공공·금융 시장 진입이 사실상 불가능합니다.

---

## 비교 기준 5가지

1. 공공 적합성 (CSAP·GPKI·국내 보관)
2. VDI·DaaS 통합
3. 가격·라이선스 모델
4. MSP 가능성 (다중 고객 관리)
5. 1인 기업의 진입 장벽

## 1. Microsoft Entra ID

### 기본 정보
- **본사**: 미국 (Microsoft) / **Azure Korea**: 서울·부산 리전, **CSAP IaaS 인증 보유**
- **제품 라인**: Free / P1 / P2 (M365 통합)
- **국내 파트너**: M365 파트너 모두 가능
- **국내 인지도**: 매우 높음 (M365 보유 모든 기관)

### 가격 (2026년 기준)
| 등급 | 1인 월 가격 | 비고 |
|---|---|---|
| **Entra ID Free** | 무료 | 기본 MFA 포함 |
| **Entra ID P1** | $6 | Conditional Access, Self-Service |
| **Entra ID P2** | $9 | + Identity Protection, PIM |
| **M365 Business Premium** | $22 | Entra ID P1 포함 |
| **M365 E3** | $36 | Entra ID P1 포함 |
| **M365 E5** | $57 | Entra ID P2 포함 |

### 공공 적합성: ★★★★★
- Azure Korea CSAP IaaS 인증 → 공공 사용 가능
- 행안부 G-Cloud 호환 검증 사례 있음
- 데이터 한국 리전 (서울/부산) 보관 가능

### VDI 통합
- ★★ Citrix NetScaler SAML 연동
- ★★ VMware Horizon SAML 연동
- ★★ Omnissa SAML 연동
- ★★★★★ AVD/Windows 365 네이티브 통합

### MSP 운영
- **CSP (Cloud Solution Provider) 프로그램** 통한 다중 고객 관리
- 단일 콘솔에서 여러 테넌트 관리 가능

### 1인 기업 진입 장벽
- ★★★★ Microsoft Partner Network 가입 쉬움
- ★★★★ M365 보유 고객은 추가 라이선스 구매 없이 활성화만
- ★★★ Microsoft 정책 잦은 변화 (학습 부담)

### 종합 평가: **★★★★★ (1순위)**
- 한국 시장 모든 영역(공공·금융·민간) 진입 가능
- M365 보유 고객 대상 즉시 시작 가능
- 1인 기업이 가장 빠르게 시작할 수 있는 벤더

## 2. 라온시큐어 (Raonsecure)

### 기본 정보
- **본사**: 한국 (라온시큐어㈜)
- **제품 라인**:
  - **OneAccess** — 통합 IAM·MFA 플랫폼
  - **TouchEn OnePass** — 모바일 SSO/OTP
  - **TouchEn nxKey** — 키보드 보안 + OTP
  - **KeyManager** — PKI 인증서 관리
- **국내 파트너**: 본사 직접 + 다수 SI
- **국내 인지도**: 공공·금융 광범위 (TouchEn 시리즈는 사실상 표준)

### 가격
- 사용자당 연 라이선스 (별도 견적)
- 공공 RFP 단가 협상 가능
- 국내 가격 정책 → 환율 변동 영향 없음

### 공공 적합성: ★★★★★
- **국내 솔루션** → 데이터 보관·국외이전 이슈 없음
- **GPKI/NPKI 행정 전자서명 네이티브 지원**
- 정부 부처·지자체·공공기관 200+ 도입 레퍼런스
- 행정안전부 인증 솔루션

### VDI 통합
- ★★★ Citrix StoreFront 연계
- ★★★ VMware UAG 연계 (RADIUS 표준)
- ★★ Omnissa 호환
- ★★ AVD/Windows 365 (SAML 통한 간접 통합)

### MSP 운영
- OneAccess 통합 콘솔 제공
- 다중 고객 정책 템플릿
- 한국 본사 직접 지원

### 1인 기업 진입 장벽
- ★★★ 라온시큐어 본사 파트너십 신청 (3~6개월 검증 기간)
- ★★★ 한국어 문서·교육 풍부
- ★★★★ 공공 RFP 응답 시 라온시큐어 기술팀 협력 가능
- ★★ 가격 정보 비공개 → 견적 협상 부담

### 종합 평가: **★★★★★ (2순위, 공공 특화)**
- 한국 공공 시장 진입의 핵심 카드
- GPKI 환경 RFP 응답 시 필수
- 단점: 파트너십 등록까지 3~6개월 소요

## 권장 전략 (1인 기업)

### Phase 1 (즉시 ~ 3개월): Microsoft Entra ID 단독 시작
- **이유**: 가장 빠른 진입, M365 보유 고객 즉시 영업 가능
- **액션**:
  1. Microsoft Partner Network 등록 (1주)
  2. M365 Business Premium / E3 / E5 차이 학습 (2주)
  3. SC-300 (Identity Administrator) 학습 시작
  4. 기존 VDI 고객 12개 기관 중 M365 보유 기관 식별 후 영업
  5. AVD/Windows 365 PoC 환경 구축

### Phase 2 (3~9개월): 라온시큐어 파트너십 추진
- **이유**: 공공 시장 진입 카드 확보 (GPKI 환경 RFP 대응)
- **액션**:
  1. 라온시큐어 본사 파트너십 신청 (3~6개월 검증)
  2. OneAccess·TouchEn OnePass 제품 학습
  3. PoC 환경 구축 (Citrix + 라온시큐어 OneAccess)
  4. 행정전자정부·지자체 RFP 모니터링

### Phase 3 (9~12개월): 드림시큐리티 또는 잉카인터넷 추가 검토
- **이유**: 특정 RFP 요건 (금융권 키패드 등) 대응
- **액션**: 라온시큐어 안착 후 검토

### 비추천: Okta, OneLogin
- 한국 공공 진입 사실상 불가
- 외국계 다국적 기업 고객만 발생 시 검토
