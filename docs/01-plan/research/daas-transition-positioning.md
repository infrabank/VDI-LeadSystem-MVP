# DaaS 전환 자문 사업 포지셔닝

> **목적**: 온프레미스 VDI에서 DaaS(Citrix DaaS, AVD, Windows 365)로 전환하려는 고객 대상 자문·구축 사업의 포지셔닝 전략.
> **시점**: 2027 Q1 ~ Q2 본격 시작 (MFA 사업 안착 후)

---

## 시장 배경

### DaaS 수요 증가 요인
1. **VDI 라이선스 부담 가속화** (Citrix·VMware 가격 상승)
2. **망분리 완화 정책** (정부 디지털 전략, 2026~)
3. **클라우드 우선 정책** (M365·Azure 도입 증가)
4. **재택·원격근무 확대** (코로나 이후 정착)
5. **운영 인력 부족** (전통 VDI 운영 인력 retire 가속)

### 시장 규모 (한국 추정)
- 2026: 약 1,500억 (DaaS 신규 도입)
- 2028: 약 3,000억 (2배 성장 예상)
- 주요 벤더: Citrix DaaS / AVD / Windows 365 / Citrix Cloud (3강 1중)

## 차별화 포지셔닝

### 경쟁사 vs Myloket

| 경쟁사 유형 | 강점 | 약점 |
|---|---|---|
| **대형 SI (삼성SDS, LG CNS)** | 풀스택 자문, 인프라 동시 | 비용 매우 높음, 1인 미만 단위 안 받음 |
| **클라우드 전문 SI (메가존, 베스핀)** | Azure·AWS 강함 | VDI 도메인 전문성 약함 |
| **Microsoft 직접 영업** | 라이선스 비용 우대 | 구축·운영 자문 약함 |
| **Citrix 직접 영업** | Citrix DaaS 전문 | AVD·Windows 365 비교 자문 X |
| **Myloket (1인 전문가)** | **VDI 도메인 + 멀티 벤더 중립 + 빠른 의사결정** | 인력 규모 (대규모 동시 PoC 부담) |

### Myloket 포지셔닝 한 문장
**"Citrix·VMware·Omnissa 운영 경험을 가진 한 전문가가, 귀사 환경에 가장 잘 맞는 DaaS 옵션을 중립적으로 제안합니다."**

### 차별화 포인트 3가지
1. **멀티 벤더 중립**: Microsoft·Citrix·VMware 어느 한쪽에 종속되지 않음
2. **빠른 의사결정**: 1인 전문가의 직접 응대 (대형 SI는 영업 → PM → 컨설턴트 경유)
3. **단일 책임**: 자문부터 구축·운영까지 한 창구

## 영업 화법 (대표 시나리오)

### 시나리오 1: Citrix VAD 사용 중인 고객 (라이선스 부담 호소)

**고객의 고민**:
- "Citrix 라이선스 비용이 매년 올라서 부담입니다"
- "AVD나 Windows 365로 옮기면 어떨까요?"

**Myloket 응대**:
> "라이선스 부담은 충분히 이해합니다. 다만 단순히 비용만으로 결정하면 운영 부담이 커질 수 있습니다.
>
> 귀사 사용자 분포(Knowledge Worker / Power User), 사용 시간 패턴, M365 보유 여부, 한국 SaaS 호환성을 먼저 점검해야 합니다.
>
> 보통 다음 3가지 옵션을 5년 TCO로 비교해드립니다:
> 1. Citrix DaaS로 클라우드 이전 (가장 호환성 高)
> 2. AVD로 마이그레이션 (M365 라이선스 활용 시 가장 저렴)
> 3. Windows 365 (운영 부담 가장 적음)
>
> 무료 상담 한 번 받아보시고, 우리 환경에 맞는 답을 찾아보시는 것을 권장합니다."

### 시나리오 2: 신규 VDI 도입 검토 중인 고객

**고객의 고민**:
- "처음 VDI 도입인데, 온프레로 구축할까 클라우드로 갈까요?"
- "재택근무자가 많아서 클라우드가 좋을 것 같은데..."

**Myloket 응대**:
> "재택 사용자가 많으면 클라우드 우선 검토가 맞습니다. 다만 다음 3가지를 사전 점검해야 합니다:
>
> 1. **데이터 분류**: C/S/O 등급 중 클라우드 가능한 데이터 비중
> 2. **한국 SaaS 호환성**: 더존, 이카운트 등 한국 ERP 라이선스 정책
> 3. **네트워크 대역폭**: 본사·지사 인터넷 회선 (사용자당 1~3 Mbps 필요)
>
> 사전 점검 결과에 따라 1~2주 내 3가지 옵션 제안서 드릴 수 있습니다."

### 시나리오 3: VMware Horizon → Broadcom 인수 후 라이선스 폭등 호소

**고객의 고민**:
- "Broadcom 인수 후 ELA 강제로 라이선스가 너무 올랐어요"
- "Horizon 그대로 갈지, Omnissa로 옮길지, AVD로 옮길지 모르겠어요"

**Myloket 응대**:
> "Broadcom 가격 정책은 정말 부담스럽죠. 옵션은 3가지입니다:
>
> 1. **Horizon 8 유지 + Broadcom ELA 갱신** (가격 협상 폭 좁음)
> 2. **Omnissa 마이그레이션** (분사 후 가격 안정화 중, 호환성 검증 필요)
> 3. **AVD/Windows 365 전환** (M365 보유 시 가성비 최고)
>
> 보통 3개월 정도의 PoC 진행 후 결정을 권장합니다. 무료 비교 분석 자료 드릴 수 있습니다."

## 무료 자문 → 유료 프로젝트 전환 흐름

### Step 1: 무료 1시간 인터뷰
- 현황 파악 (사용자 수·솔루션·라이선스·예산)
- 고민·요구사항 청취
- 적합한 옵션 1~3개 제시

### Step 2: 무료 비교 분석 자료 (5일 내)
- 3가지 옵션 5년 TCO 비교표
- 마이그레이션 일정 초안
- 위험 요소·고려사항 정리

### Step 3: 유료 PoC (1~2개월, 500~1500만원)
- 10~30명 파일럿 그룹 대상 PoC
- 골든 이미지 구축
- 성능·사용자 만족도 테스트

### Step 4: 유료 마이그레이션 (3~6개월, 5000만원~3억)
- 단계적 마이그레이션 (Wave 1~3)
- 사용자 교육
- 온프레 환경 단계적 종료

### Step 5: 유료 MSP 운영 (월 정액)
- 모니터링·알림
- 비용 모니터링
- 분기별 리포트

## 가상 RFP 응답 (예시 1건)

### RFP 시나리오: 중견 제조업, 사용자 200명

**고객 환경**:
- VMware Horizon 7 사용 중 (Broadcom ELA 부담)
- M365 E3 보유
- 본사 + 공장 2곳 분산
- 재택근무 30%

**RFP 요구사항**:
- 5년 TCO 30% 절감
- M365 통합 유지
- 한국 ERP(더존) 호환
- 재택·외근 환경 보안 강화

### Myloket 제안서 요약

#### 권장 옵션: AVD (Azure Virtual Desktop) + FSLogix 프로파일

**근거**:
- M365 E3 라이선스에 AVD 사용 권한 포함 → 라이선스 추가 비용 0
- Azure 한국 리전 사용 → 더존 호환성 검증 가능
- 재택 사용자 → Azure Front Door로 글로벌 접근 가능
- Microsoft Entra MFA + Conditional Access → 보안 강화

**5년 TCO 비교**:

| 항목 | Horizon 8 (Broadcom) | AVD | Windows 365 |
|---|---|---|---|
| **라이선스** | 4억 (ELA) | 0 (M365 포함) | 7.4억 |
| **인프라** | 3억 (서버 갱신) | 6억 (Azure 컴퓨트) | 0 |
| **운영 인력** | 4억 | 3억 | 1억 |
| **마이그레이션** | 0 | 1억 | 1.5억 |
| **5년 총** | **11억** | **10억** | **9.9억** |

**Myloket 제안 근거**:
- AVD 비용 = Windows 365 비슷, but **유연성 높음** (커스터마이징 가능)
- Microsoft·Acronis 인증 파트너로 통합 운영 가능
- 18개월 마이그레이션 일정 (사용자 영향 최소화)

#### 도입 일정

| 단계 | 기간 | 활동 |
|---|---|---|
| Phase 1 | 1~2개월 | 사전 평가, 더존 호환성 검증 |
| Phase 2 | 1~2개월 | PoC (30명, 본사 IT팀) |
| Phase 3 | 6~9개월 | 단계적 마이그레이션 (Wave 1~3) |
| Phase 4 | 3개월 | 운영 안정화, MSP 정착 |

#### Myloket 제안 가격

| 항목 | 비용 |
|---|---|
| 사전 평가 | 무료 |
| PoC | 1,500만원 |
| 마이그레이션 (200명) | 1.2억 |
| 운영 인력 (3년) | 9,000만원 |
| **총** | **2.25억** |
