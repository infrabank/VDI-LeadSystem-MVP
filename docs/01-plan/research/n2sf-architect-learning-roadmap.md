# N²SF 학습 로드맵 — VDI 출신 1인 기업 운영자용

> **목적**: VDI 다년 경력자가 N²SF 시류에 부합하는 "실무 전문가" 포지션을 확보하기 위한 자가 학습 경로.
> **전제**: 본격 N²SF 컨설팅 라벨로 단독 어필은 비추천. "VDI·MFA·백업을 N²SF 관점으로 정리해주는 실무 전문가" 포지션을 목표로 함.
> **기간**: 12개월 (단계별 병행 가능)

### 학습 자료
- **국정원 N²SF 가이드라인 v1.0 본문** (이미 추출 완료, `reference_n2sf_extracted_docs.md` 참조)
- **부록1·2** (11 모델 시나리오 매핑)

### 핵심 학습 포인트
- **274개 보안통제** 카테고리별 그룹핑
  - AC (접근통제), IA (식별인증), SC (통신보호)
  - SI (시스템무결성), CP (비상계획)
  - MA (다요소인증), AM (접근관리), DA (디바이스인증)
  - RA (원격접속), EB (엔드포인트경계), SG (분리/게이트웨이)
  - IS (정보저장), DU (데이터사용), AC (감사)
- **C/S/O 등급 체계**
  - C(기밀) - 국가비밀, 핵심 기반시설
  - S(민감) - 개인정보, 영업비밀
  - O(공개) - 일반 정보
- **11개 모델 시나리오**
  - 모델 3: SaaS 협업 (O 등급 한정)
  - 모델 8: 통합문서 (S+O 혼재 한정)
  - 모델 10: 무선 접속

### 산출물

- "N²SF 통제 카테고리 한 장 요약" 차트

### 학습 시간
- 주 5시간 × 8주 = 40시간

## 단계 2 — Zero Trust·망분리 완화 흐름 (2~3개월)

### 학습 자료
- **NIST SP 800-207** Zero Trust Architecture (영문 60p, 무료)
- **CISA Zero Trust Maturity Model v2.0** (5 pillars)
- 국정원 **"망분리 완화 정책"** 변화 흐름 (2023~2026)

### 핵심 학습 포인트

#### Zero Trust 5 Pillars (CISA ZTMM v2.0)
1. **Identity** — 사용자 인증·권한
2. **Device** — 디바이스 신뢰도·무결성
3. **Network** — 네트워크 분리·암호화
4. **Application & Workload** — 앱 단위 격리
5. **Data** — 데이터 분류·암호화

#### VDI가 Zero Trust에서 차지하는 위치
- VDI는 Device + Network + App 3 pillar 동시 충족 솔루션
- 이미 강점인 영역 → Zero Trust 자문 자연스럽게 확장 가능

#### 망분리 완화 흐름
- 2023: 정부 디지털 전략 → 망분리 완화 검토 시작
- 2024~2025: 가이드라인 정비, 시범 적용
- 2026: N²SF 1.0 시행, 본격 완화

### 산출물
- "VDI 운영자가 알아야 할 Zero Trust 5 Pillars 매핑표"
- 자가 학습 노트

### 학습 시간
- 주 5시간 × 12주 = 60시간

## 단계 3 — 인접 솔루션 카테고리 (3~6개월, 실습 병행)

### 학습 영역 (5개)

#### 1. MFA / IAM
- **벤더**: Microsoft Entra ID (1순위), 라온시큐어 OneAccess (2순위, 공공), 드림시큐리티 MagicLine, 잉카인터넷 nProtect
- **VDI 접점**: VDI 진입 인증 강화 (가장 가까운 확장)
- **학습 방법**: Microsoft Learn (SC-300) + 라온시큐어 OneAccess 자료 + 자체 PoC
- **시간**: 30시간 + 자체 PoC 환경 구축 30시간
- **주의**: Okta·OneLogin은 CSAP 인증 부재로 한국 공공 진입 불가, 학습 우선순위 낮음

#### 2. ZTNA / SASE (이해만, 직접 딜리버리 X)
- **벤더**: Zscaler, Cloudflare, Cato Networks
- **VDI 접점**: VDI의 보완재(대체 X), 외부 협력사 접근용
- **학습 방법**: 벤더 백서·웨비나 (각 벤더 무료)
- **시간**: 20시간

#### 3. EDR / XDR
- **벤더**: Acronis EDR, CrowdStrike, SentinelOne, Microsoft Defender
- **VDI 접점**: VDI 골든이미지·세션 보호
- **학습 방법**: Acronis EDR(이미 보유) 실습 + Microsoft Defender 트라이얼
- **시간**: 30시간

#### 4. DLP / CASB
- **벤더**: Microsoft Purview, Netskope
- **VDI 접점**: 망분리 완화 시 데이터 유출 통제 보완
- **학습 방법**: Microsoft Learn (SC-400 일부)
- **시간**: 20시간

#### 5. PAM (이해만)
- **벤더**: CyberArk, Delinea
- **VDI 접점**: VDI 관리자 계정 보호
- **학습 방법**: 벤더 백서
- **시간**: 10시간

### 산출물
- 카테고리별 1장 요약 (사이트 콘텐츠로 활용)
- Acronis EDR PoC 환경 구축 결과 정리 (Microsoft Entra + 라온시큐어 OneAccess)

### 학습 시간
- 총 120시간 (3~6개월에 분산)

## 단계 4 — 자격증 (선택·후순위)

### 권장 자격증 (가성비 순)

#### 1순위: ISMS-P 인증심사원 (국내 가성비 ↑)
- **소요**: 3~4개월 학습 + 시험
- **비용**: 교육 100~200만원, 시험 무료
- **가치**: N²SF 컨설팅 RFP에서 가산점, 국내 인지도 高
- **권장 시점**: 단계 3 완료 후

#### 2순위: Microsoft SC-100 (Cybersecurity Architect Expert)
- **소요**: 2~3개월 (이미 SC-200, SC-300 보유 시)
- **비용**: 시험 $165
- **가치**: M365·Azure Zero Trust 통합 설계 능력 증명
- **권장 시점**: MFA 사업 안착 후

#### 3순위: AZ-500 (Azure Security Engineer)
- **소요**: 2개월
- **비용**: 시험 $165
- **가치**: AVD/Windows 365 사업 진출 시 필수
- **권장 시점**: DaaS 전환 사업 시작 시

#### 후순위: CISSP (글로벌 톤업, 시간·비용 大)
- **소요**: 6~12개월
- **비용**: 시험 $749 + 교육 200~300만원
- **가치**: 글로벌 인지도, 5년 경력 인증 필요
- **권장 시점**: 사업 안정 후 검토

### 비용·시간 총계 (1·2·3순위 모두 취득 시)
- 시간: 약 9~12개월 (1·2·3순위 순차)
- 비용: 약 350~500만원

## 단계 5 — 실전 자산 축적 (병행)

### 가상 RFP 시나리오 작성 (3개)

- 신뢰 자산 축적
- 시드 015 8건 + 월 1~2건 추가 = 1년 후 약 20~30건 콘텐츠

## 현실 조언

### "전문 아키텍트" 라벨 단독 어필은 비추천
- 1인 기업이 단독으로 "N²SF 전문 아키텍트" 라벨 어필은 시장 적합도 낮음
- 대신 **"VDI·MFA·백업을 N²SF 관점으로 정리해주는 실무 전문가"** 포지션이 현실적

### 본격 N²SF 컨설팅은 협업 모델로
- 대형 SI·보안 컨설팅사와 협업/하청 모델
- 직접 RFP 수주 X, 솔루션 딜리버리 파트너로 참여
- 자체 사이트는 체크리스트·자가진단 수준 애드온만

### 우선순위
1. **MFA 사업 즉시 시작** (단계 3 일부와 병행)
2. **Acronis EDR 확장** (3~6개월)
3. **ISMS-P 인증심사원** (가성비 가장 높음)
4. **DaaS 전환 자문** (6~12개월, AZ-500과 함께)
5. **N²SF 학습은 사업 활동의 보조 자료로** (절대 메인 포지션으로 어필 X)
