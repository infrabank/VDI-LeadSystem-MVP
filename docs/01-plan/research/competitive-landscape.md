# 경쟁 환경 매핑 — VDI·MFA·백업 시장

> **목적**: Myloket이 진출하려는 4개 솔루션 영역(VDI/MFA/백업·EDR/융합)에서 경쟁사를 매핑하고 차별화 포인트를 명확히 한다.
> **결론**: "1인 전문가 + 멀티 벤더 중립 + 빠른 의사결정 + 단일 책임" 4가지로 차별화 가능.

---

## 경쟁사 매핑 (4가지 유형)

### 유형 1: 대형 SI (삼성SDS, LG CNS, SK C&C)

#### 강점
- 풀스택 자문 (보안 전략 + 인프라 + 운영)
- 풍부한 인력·자격증 보유
- 대형 RFP 수주 가능
- 글로벌 벤더와 직접 파트너십

#### 약점
- 비용 매우 높음 (소형 프로젝트 안 받음)
- 의사결정 느림 (영업 → 컨설턴트 → PM → 실무자 경유)
- 대규모 프로젝트 위주 → 50인 미만 고객 응대 X
- 표준화된 답변 (개별 환경 세심한 맞춤 어려움)

#### Myloket 차별화 vs 대형 SI
- **타겟**: 50~500인 중견 시장 (대형 SI 관심 밖)
- **속도**: 1인 전문가 직접 응대 → 영업 첫 미팅 후 1~2주 내 제안서
- **비용**: 대형 SI 대비 30~50% 저렴 (오버헤드 없음)

### 유형 2: 클라우드 전문 SI (메가존, 베스핀, 굿어스)

#### 강점
- Azure·AWS 강함
- DaaS·클라우드 마이그레이션 전문
- 빠른 클라우드 트렌드 적응

#### 약점
- VDI 도메인 전문성 약함 (특히 Citrix 깊이)
- MFA·백업은 보조 영역
- 1인 미만 단위 안 받음 (소형 프로젝트 보류)

#### Myloket 차별화 vs 클라우드 SI
- **VDI 깊이**: Citrix·VMware·Omnissa 다년 운영 경험 (클라우드 SI는 AVD 위주)
- **하이브리드**: 온프레 + 클라우드 동시 운영 자문 가능
- **소형 응대**: 30~50인 규모도 환영

### 유형 3: 보안 컨설팅사 (안랩, 시큐아이, 라온시큐어)

#### 강점
- 보안 컨설팅 전문 (ISMS-P, 모의해킹)
- 정부·금융권 인증 받기 쉬움
- N²SF 컨설팅 경험 보유 가능성

#### 약점
- VDI·MFA 솔루션 딜리버리는 보조
- 컨설팅 위주 → 구축·운영 책임 X
- 비용 비쌈 (정부 표준 단가 적용)

#### Myloket 차별화 vs 보안 컨설팅사
- **솔루션 딜리버리**: 컨설팅이 아닌 실제 도입·구축·운영
- **VDI·MFA·백업 통합**: 보안 컨설팅사는 솔루션 단편
- **N²SF 자가 점검 도구**: 컨설팅사는 자체 도구 적음

### 유형 4: 1인/소규모 전문가 (직접 경쟁사)

#### 시장 추정
- 한국 내 VDI 1인/소규모 전문가: 약 50~100명 추정 (Citrix·VMware 인증자 기준)
- 상당수는 프리랜서·하청 형태
- 자체 사이트·콘텐츠 운영하는 1인 전문가는 매우 드뭄

#### 직접 경쟁사 강점·약점
- **강점**: 직접 응대, 빠른 의사결정, 저렴한 비용
- **약점**: 대부분 사이트·콘텐츠 부재 (영업 채널 부족), 멀티 벤더 X (한 벤더 종속), 단일 영역 (VDI만 또는 백업만)

#### Myloket 차별화 vs 1인 전문가
- **사이트·진단 도구·콘텐츠**: 인바운드 영업 채널 보유 (대부분 1인 전문가는 추천 의존)
- **멀티 벤더**: Citrix·VMware·Omnissa·Acronis·MFA·DaaS 통합 자문
- **융합 패키지**: 4개 영역 통합 설계 (대부분 1인 전문가는 한 영역만)

   고가      │              │ 대형 SI      │

## 차별화 포인트 4가지

### 1. 1인 전문가의 직접 응대
- **고객 가치**: 첫 미팅이 곧 의사결정자와의 미팅
- **경쟁 우위**: 대형 SI 대비 5~10배 빠른 의사결정
- **검증 방법**: 영업 컨택 후 첫 제안서까지 1~2주

### 2. 멀티 벤더 중립
- **고객 가치**: 특정 벤더에 종속되지 않은 객관적 자문
- **경쟁 우위**: 대형 SI는 자사 라이선스 우선 / 벤더 직영은 자사 제품만
- **검증 방법**: 3개 옵션 (Citrix vs Horizon vs Omnissa) 5년 TCO 비교 제공

### 3. VDI·MFA·백업 통합
- **고객 가치**: 도입 후 책임 단절 해소
- **경쟁 우위**: 1인 전문가가 4개 영역 통합 운영 가능 (다른 곳은 영역별 분산)
- **검증 방법**: 융합 패키지 시나리오 3종 제공

### 4. 단일 책임 운영(MSP)
- **고객 가치**: 도입 후에도 한 창구에서 책임
- **경쟁 우위**: 대형 SI는 도입 후 MSP 별도 계약·인력 / 1인 전문가는 MSP 운영 부담 큼
- **검증 방법**: Acronis Cyber Protect Cloud (MSP) 통합 콘솔 활용

## 약점·위험 요소

### 약점 1: 인력 규모 한계
- **현실**: 1인 운영 → 대규모 동시 PoC·구축 부담
- **대응**:
  - 50~500인 규모 시장에 집중 (대규모 시장은 안 함)
  - 외주 파트너십 (필요 시 다른 1인 전문가와 협업)
  - 18개월 후 인력 영입 검토

### 약점 2: 인지도 빌드 부담
- **현실**: 대형 SI·벤더 직영은 브랜드 신뢰 자동
- **대응**:
  - 사이트 콘텐츠로 SEO 빌드 (이미 진행 중)
  - 자가 진단 도구로 인바운드 리드 생성
  - 첫 도입 사례 콘텐츠화 (익명화)

### 약점 3: 자격증·인증 부재
- **현실**: ISMS-P, CISSP 등 부재 시 RFP 평가에서 불리
- **대응**:
  - 12개월 내 ISMS-P 인증심사원 취득
  - 24개월 내 SC-100, AZ-500 취득
  - 대형 SI와 협업/하청 형태로 RFP 참여 (단독 수주 X)

### 약점 4: 신뢰 빌드 시간
- **현실**: 1인 기업은 신규 고객이 망설일 수 있음
- **대응**:
  - 기존 13개 고객 레퍼런스 적극 활용 (익명화)
  - 무료 자문·진단 도구로 사전 신뢰 빌드
  - 첫 도입은 작은 규모 (PoC) → 단계적 확대

| 채널 | 대형 SI | Myloket |
|---|---|---|
| **공공 RFP** | 직접 수주 | 협업·하청만 (단독 X) |
