## 1. Google 비즈니스 프로필 (GBP)

### 절차

1. https://business.google.com 접속 → 구글 계정 로그인 (회사 관리용 계정 권장)
2. "지금 관리하기" → 비즈니스 이름에 **(주)마이로켓** 입력
3. 비즈니스 유형: **온라인 소매 아님 / 오프라인 매장 아님 → "서비스 제공 지역 비즈니스"** 선택
   - 고객이 사무실로 방문하는 업태가 아니므로, 주소는 등록하되 "고객에게 주소 표시" 여부는
     선택 가능. 표시 권장(신뢰 근거) — 단, 원치 않으면 숨기고 서비스 지역만 노출.
4. 카테고리 (기본 1 + 추가):
   - 기본: **컴퓨터 지원 및 서비스 (Computer Support and Services)**
   - 추가: 컴퓨터 컨설턴트(Computer Consultant), 소프트웨어 회사(Software Company)
5. 서비스 지역: 세종특별자치시, 대전광역시, 청주시, 천안시
   (VDI 원격 기술지원은 전국이지만, GBP 서비스 지역은 방문 가능 범위 기준으로 입력)
6. 전화·웹사이트 입력 (위 NAP 표 그대로)
7. **인증(Verification)**: 주소 우편엽서(2주), 전화, 이메일, 영상 인증 중 구글이 제시하는
   방법 선택. 영상 인증이 가장 빠른 경우가 많음 (사무실 간판·내부·장비를 촬영).
8. 인증 완료 후: 설명·서비스·사진·영업시간 입력 (아래 문구 사용)

## 2. 네이버 스마트플레이스

### 절차

1. https://smartplace.naver.com 접속 → 네이버 계정 로그인
2. "신규 등록" → 사업자 등록 방식 선택 → **사업자등록번호 216-88-00409** 입력
   (국세청 조회로 상호·대표자 자동 확인됨)
3. 업체명: **(주)마이로켓** — 키워드를 붙인 "마이로켓 VDI 기술지원" 같은 변형 금지
   (네이버 가이드라인 위반으로 노출 불이익)
4. 업종 카테고리: **컴퓨터수리 아님** → "IT·컴퓨터 > 시스템·네트워크 유지보수" 계열 또는
   "서비스,산업 > 소프트웨어개발" 중 검색해 가장 근접한 것 선택 (검색창에 "전산 유지보수",
   "시스템 유지보수"로 검색하면 후보가 나옴)
5. 주소·전화·홈페이지 입력 (NAP 표 그대로)
6. 사업자등록증 첨부 → 제출 → **검수 1~3영업일**
7. 승인 후: 소개글·대표 키워드·사진·영업시간 입력 (아래 문구 사용)
