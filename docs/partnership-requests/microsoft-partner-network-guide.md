## 2단계: Indirect Reseller 자격 (가장 현실적, 1~2개월)

### 왜 Indirect Reseller인가

| 옵션 | 진입 장벽 | 1인 기업 적합성 |
|---|---|---|
| **Direct CSP (Tier 1)** | 매우 높음 (연 매출·자체 청구·24x7 지원) | ❌ 부담 |
| **Indirect Reseller (Tier 2)** | 낮음 (디스트리뷰터 통해 진행) | ✅ 권장 |
| **Open License Reseller** | 종료 (2022년 이후 신규 X) | - |

### Indirect Reseller 절차

1. **Partner Center → "CSP" 메뉴 → "Indirect Reseller"** 신청
2. 디스트리뷰터 선택 (최소 1곳)
3. 디스트리뷰터와 **Reseller 계약** 체결 (NDA + 마진 협의)
4. 디스트리뷰터 portal 가입 → 라이선스 견적·발주·청구 자동화
5. 첫 고객 거래 시 디스트리뷰터 통해 진행

### 마진 구조 (참고)

| 라이선스 | 디스트리뷰터 마진 | Reseller(자사) 마진 |
|---|---|---|
| **M365 Business Premium** | 10~15% | 5~10% |
| **M365 E3/E5** | 8~12% | 5~8% |
| **Entra ID P1/P2** | 10~15% | 5~10% |
| **Windows 365** | 10~15% | 5~10% |
| **Azure Reserved Instance** | 5~10% | 3~7% |

> 디스트리뷰터 협상에 따라 ±5% 변동. 첫 거래 후 누적 매출 늘면 마진 인상 협상 가능.

## 4단계: 한국 MS 파트너 매니저(PDM) 컨택

### Partner Development Manager (PDM)란

- Microsoft Korea가 파트너에게 배정하는 영업 매칭·교육·이벤트 담당자
- Network Member는 자동 배정 X, **Solutions Partner 자격 또는 일정 매출 달성** 시 배정
- 1인 기업도 적극 컨택하면 PDM 배정 가능 (단, 영업 활동 증명 필요)

### 컨택 방법

1. **partner.microsoft.com → Help & Support** → 한국 매니저 매칭 요청
2. **Microsoft Korea SMB&P 부서 직접 컨택** (`microsoft-partner-manager-contact.md` 참조)
3. **Microsoft Korea 행사 참석** (Microsoft Build Korea, Ignite Korea 등) → 명함 교환

### 컨택 시점

- Indirect Reseller 등록 완료 후 (1~2개월 후)
- 첫 고객 거래 1~3건 발생 후 (영업 활동 증명)
